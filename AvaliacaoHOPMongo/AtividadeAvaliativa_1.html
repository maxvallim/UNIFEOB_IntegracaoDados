Atividade Avaliativa - Integração de Dados

Nesta atividade você realizará um processo completo de integração de dados utilizando PostgreSQL, Apache Hop e MongoDB.

O objetivo é transformar registros de um banco relacional em documentos JSON e armazená-los em uma coleção MongoDB.

Objetivo

Uma empresa possui um sistema transacional armazenado em PostgreSQL contendo informações de clientes, produtos, vendas e itens de venda.

Seu trabalho será gerar documentos JSON representando cada venda e realizar a carga desses documentos para um banco MongoDB utilizando Apache Hop.

Parte 1 - Preparação do Banco PostgreSQL

  1. Crie um banco PostgreSQL vazio.
  2. Abra o DBeaver.
  3. Conecte-se ao banco criado.
  4. Execute completamente o arquivo 01_Tabelas_SQL.txt (*DICA FORTE - Execute primeiro o scripts de criação das tabelas e depois o de inserção de dados).
  5. Confirme a criação das tabelas.

Tabelas Esperadas

  • clientes
  • produtos
  • vendas
  • itensVendas
Dica: Execute os comandos abaixo para validar a carga: 
SELECT COUNT(*) FROM clientes;

SELECT COUNT(*) FROM produtos;

SELECT COUNT(*) FROM vendas;

SELECT COUNT(*) FROM itensvendas;

Parte 2 - Entendendo o Documento JSON (script do arquivo SelectJson.txt)

A consulta SQL fornecida gera documentos JSON semelhantes ao exemplo abaixo: 

{
   "_id": 100,

   "dataVenda": "2026-09-25",

   "cliente": {
      "id": 20,
      "nome": "Cliente 0020",
      "cep": "59010-000"
   },

   "itens": [
      {
         "idProduto": 4,
         "descricao": "Perfume Floral Elegance",
         "quantidade": 2,
         "valorUnitario": 129.90,
         "valorTotal": 259.80
      }
   ],

   "totalVenda": 259.80
}
Observe:
  • Uma venda gera um documento.
  • O cliente fica armazenado dentro do documento.
  • Os itens ficam armazenados em uma lista.
  • O total da venda é calculado automaticamente.

Parte 3 - Testando a Consulta SQL

  1. Abra o arquivo 02_SelectJson.txt.
  2. Copie a consulta SQL.
  3. Execute a consulta no PostgreSQL utilizando DBeaver.
  4. Analise os resultados.
Dica: O resultado deverá apresentar uma coluna chamada: 
documento
Essa coluna contém o JSON completo que será enviado para o MongoDB.

Parte 4 - Construção do Pipeline Apache Hop

Crie um pipeline utilizando a estrutura abaixo: 

Table Input
      ↓
MongoDB Output

Configuração do Table Input

  • Criar conexão PostgreSQL.
  • Testar a conexão.
  • Inserir a consulta contida em 02_SelectJson.txt.
  • Executar Preview.
Se o Preview mostrar uma coluna chamada documento, contendo JSON, essa etapa foi concluída corretamente.

Configuração do MongoDB Output

  • Criar conexão MongoDB.
  • Informar a Database.
  • Informar a Collection.
  • Configurar a gravação dos documentos JSON.

Parte 5 - Executando a Integração

Execute o pipeline completo.

O processo deverá realizar:

  1. Leitura dos dados do PostgreSQL.
  2. Execução da consulta SQL.
  3. Geração dos documentos JSON.
  4. Carga dos documentos no MongoDB.

Parte 6 - Validação

Utilizando MongoDB Compass apresente:

  • Database criada.
  • Collection criada.
  • Quantidade de documentos inseridos.
  • Pelo menos três documentos armazenados.
Compare um documento armazenado no MongoDB com os dados existentes no PostgreSQL.
