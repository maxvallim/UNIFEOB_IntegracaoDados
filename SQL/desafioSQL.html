Agora é a sua vez! Após praticarmos consultas com JOIN, Subconsultas, EXISTS, GROUP BY, HAVING, UNION, Funções de Data, CASE e Window Functions, resolva os desafios abaixo utilizando os conhecimentos adquiridos durante a aula.

Desafio Principal

A empresa deseja identificar clientes que realizaram compras relevantes e entender quais produtos participaram dessas vendas.

Exibir:

  • Nome do cliente
  • Cidade
  • Valor do pedido
  • Data do pedido
  • Nome do produto
  • Preço do produto

Condições:

  1. Mostrar apenas clientes que possuam pelo menos um pedido acima da média geral dos pedidos.
  2. Mostrar apenas produtos cujo preço seja superior à média da sua própria categoria.
  3. Mostrar apenas pedidos realizados em 2025.
  4. Ordenar o resultado pelo valor do pedido do maior para o menor.
Importante: o exercício deve ser resolvido sem consultar os exemplos anteriores. Identifique quais recursos SQL serão necessários para atender todos os requisitos.

Desafio Bônus

Descubra qual é o produto mais caro de cada categoria.

Exibir:

  • Categoria
  • Nome do produto
  • Preço

Regras:

  • Retornar apenas um produto por categoria.
  • Ordenar as categorias em ordem alfabética.

Desafio Mestre Jedi ⭐

A empresa deseja classificar seus clientes conforme o valor total já comprado.

Classificações:

  • Bronze: até R$ 1.000,00
  • Prata: de R$ 1.001,00 até R$ 5.000,00
  • Ouro: acima de R$ 5.000,00

Exibir:

  • Nome do cliente
  • Total comprado
  • Classificação

Regras:

  • Considerar todos os pedidos realizados pelo cliente.
  • Ordenar do maior total comprado para o menor.
Dica: Antes de começar a programar, identifique quais comandos SQL estudados hoje podem ajudar a resolver cada desafio.
