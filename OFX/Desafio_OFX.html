Leitura de Arquivos OFX com Python

Nesta atividade desenvolveremos uma aplicação simples capaz de realizar a leitura de arquivos bancários no formato OFX (Open Financial Exchange). Esse formato é amplamente utilizado por instituições financeiras para exportação de extratos bancários.

Ao final desta aula o aluno será capaz de importar um arquivo OFX, percorrer suas movimentações financeiras e exibir os dados utilizando Python.

Objetivos da Aula

  • Instalar bibliotecas externas com pip;
  • Ler arquivos OFX;
  • Percorrer coleções de objetos;
  • Exibir movimentações financeiras;
  • Aplicar conceitos de processamento de dados;
  • Preparar a base para futuras integrações com banco de dados.

Estrutura do Projeto

ProjetoOFX
│
├── main.py
├── extrato.ofx
└── venv (opcional)

Passo 1 - Criando o Projeto

Crie uma pasta denominada: 

ProjetoOFX

Dentro dessa pasta crie o arquivo: 

main.py

Passo 2 - Criando o Ambiente Virtual (Opcional)

Abra o terminal do Visual Studio Code e execute: 

python -m venv venv

Ativação no Windows:

venv\Scripts\activate

Passo 3 - Instalando a Biblioteca

Instale a biblioteca responsável pela leitura dos arquivos OFX: 

pip install ofxparse

Passo 4 - Obtendo um Arquivo OFX

Utilize um arquivo OFX exportado de uma instituição financeira ou o arquivo disponibilizado pelo professor.

Salve-o na pasta do projeto com o nome: 

extrato.ofx

Passo 5 - Desenvolvendo o Programa

Digite o código abaixo no arquivo main.py: 

from ofxparse import OfxParser

with open("extrato.ofx", "rb") as arquivo:
    ofx = OfxParser.parse(arquivo)

for transacao in ofx.account.statement.transactions:

    print(
        transacao.date,
        transacao.amount,
        transacao.memo
    )

Passo 6 - Executando o Programa

No terminal execute: 

python main.py

Saída esperada: 

2026-01-05 1500.00 PIX CLIENTE
2026-01-06 -250.00 CONTA DE ENERGIA
2026-01-07 -75.50 INTERNET

Melhorando a Apresentação dos Dados

Podemos tornar a saída mais amigável ao usuário. 

from ofxparse import OfxParser

with open("extrato.ofx", "rb") as arquivo:
    ofx = OfxParser.parse(arquivo)

print("EXTRATO BANCÁRIO")

for t in ofx.account.statement.transactions:

    print(f"""
Data      : {t.date.strftime('%d/%m/%Y')}
Valor     : R$ {t.amount:.2f}
Descrição : {t.memo}
--------------------------------------
""")

Atividade Prática

Desenvolva uma aplicação que apresente:

  • Data da movimentação;
  • Valor da transação;
  • Descrição da operação;
  • Quantidade total de movimentações encontradas.

Ao final da execução, exiba também:

  • Total de entradas;
  • Total de saídas;
  • Saldo calculado.

Exemplo de Lógica para Totais

entradas = 0
saidas = 0

for t in ofx.account.statement.transactions:

    if t.amount > 0:
        entradas += t.amount
    else:
        saidas += t.amount

saldo = entradas + saidas

print(f"Entradas: R$ {entradas:.2f}")
print(f"Saídas: R$ {saidas:.2f}")
print(f"Saldo: R$ {saldo:.2f}")

Desafio Extra - PostgreSQL

Após realizar a leitura do arquivo OFX, desenvolva uma solução capaz de armazenar automaticamente as movimentações bancárias em um banco PostgreSQL.

Crie a tabela abaixo: 

CREATE TABLE movimentacoes (
    id SERIAL PRIMARY KEY,
    data_movimentacao DATE,
    valor NUMERIC(15,2),
    descricao VARCHAR(255)
);

Requisitos do desafio:

  • Instalar a biblioteca psycopg2;
  • Criar a conexão com PostgreSQL;
  • Ler as movimentações do arquivo OFX;
  • Inserir cada transação na tabela;
  • Validar os registros utilizando o DBeaver.

Desafio bônus: implementar uma validação que impeça a gravação de transações duplicadas.

Conceito Aplicado

Esta atividade representa uma implementação simplificada de um processo ETL (Extração, Transformação e Carga de Dados), muito utilizado em escritórios contábeis, instituições financeiras e sistemas de integração.
