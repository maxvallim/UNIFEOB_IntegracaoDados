Criação de Conta no Neon e Conexão com PostgreSQL pelo DBeaver

Este tutorial apresenta a criação de uma conta no Neon, a criação de um banco PostgreSQL em nuvem e a configuração da conexão pelo DBeaver.

Parte 1 - Criando a Conta

https://neon.com

Clique em Sign Up e crie sua conta.

Parte 2 - Criando o Projeto

Create Project

Crie um projeto e anote os dados de conexão.

Parte 3 - Entendendo a String de Conexão

O Neon fornece uma URL semelhante a:

postgresql://neondb_owner:SENHA@ep-exemplo.sa-east-1.aws.neon.tech/neondb?sslmode=require

Muitos alunos cometem o erro de copiar toda essa informação para o campo Host do DBeaver. Isso está incorreto.

A URL é composta pelas seguintes partes:

postgresql://          -> protocolo
neondb_owner           -> usuário
SENHA                  -> senha
ep-exemplo...tech      -> host
neondb                 -> banco de dados
sslmode=require        -> parâmetro SSL

Parte 4 - Configuração Correta no DBeaver

Ao utilizar a opção Host, cada informação deve ser colocada em seu respectivo campo.

Host:
ep-exemplo.sa-east-1.aws.neon.tech

Porta:
5432

Banco de dados:
neondb

Usuário:
neondb_owner

Senha:
(senha fornecida pelo Neon)

Não coloque a URL completa no campo Host.

Exemplo INCORRETO:

neondb_owner:senha@ep-exemplo.aws.neon.tech/neondb?sslmode=require

Exemplo CORRETO:

ep-exemplo.aws.neon.tech

Parte 5 - Configuração SSL

Na aba SSL configure:

Modo SSL:
require

Deixe vazios os campos:

Certificado CA
Certificado de cliente
Chave privada de cliente

Parte 6 - Testando a Conexão

Testar conexão

Se todos os dados estiverem corretos o DBeaver exibirá uma mensagem de sucesso.

Dica do Professor

Os erros mais comuns são:

  • Informar a URL completa no campo Host.
  • Utilizar o banco postgres quando o banco criado é neondb.
  • Informar usuário diferente do fornecido pelo Neon.
  • Não configurar SSL como require.

Se ocorrer erro, confira primeiro Host, Banco, Usuário e SSL.
