Integração de Dados - Projeto IntegraData

Nesta aula construiremos um processo completo de integração de dados utilizando APIs REST desenvolvidas em Python. O objetivo é demonstrar como diferentes sistemas podem compartilhar informações para consolidar dados de um cliente em uma única base corporativa.

Objetivos da Aula

  • Compreender os conceitos de integração de dados.
  • Utilizar APIs REST para comunicação entre sistemas.
  • Consumir dados provenientes de múltiplos bancos de dados.
  • Consolidar informações em um banco NoSQL.
  • Exportar dados para planilhas Excel.

Cenário Proposto

A empresa LojaTech possui suas informações distribuídas em diferentes sistemas:

  • Cadastro de Clientes → SQLite
  • Compras → PostgreSQL
  • Informações Financeiras → Firebase
  • Consolidação dos Dados → MongoDB
  • Relatórios → Excel

Nossa missão será construir uma sequência de APIs capazes de integrar todas essas fontes.

Parte 2 - Preparação das Bases de Dados

SQLite - Cadastro de Clientes

CREATE TABLE clientes
(
    codigo INTEGER PRIMARY KEY,
    nome TEXT,
    endereco TEXT,
    cidade TEXT
);

INSERT INTO clientes VALUES
(1,'João Silva','Rua A','Campinas'),
(2,'Maria Souza','Rua B','São Paulo');

PostgreSQL - Compras

CREATE TABLE compras
(
    id SERIAL,
    codigo_cliente INTEGER,
    data_compra DATE,
    valor NUMERIC(10,2)
);

(codigo_cliente,data_compra,valor)
VALUES

Parte 3 - API 1: Importação de Clientes

A primeira API será responsável por receber um arquivo CSV contendo os códigos dos clientes que deverão ser processados.

Arquivo CSV

codigo_cliente
1
2

Endpoint

POST /importar-clientes

Retorno Esperado

{
  "processados": 2
}

Conceitos Trabalhados

  • Upload de Arquivos
  • Leitura de CSV
  • Validação de Dados
  • JSON

Parte 4 - API 2: Consulta de Compras

Esta API acessará o PostgreSQL para recuperar o histórico de compras do cliente.

Endpoint

GET /compras/1

Exemplo SQL

SELECT *
FROM compras
WHERE codigo_cliente = 1;

Retorno

[
   {
      "valor":1500
   },
   {
      "valor":2000
   }
]

Conceitos Trabalhados

  • Conexão PostgreSQL
  • Consultas SQL
  • Serialização JSON

Parte 5 - API 3: Consulta de Cadastro

Esta API consultará o banco SQLite para recuperar os dados cadastrais do cliente.

Endpoint

GET /cliente/1

Retorno

{
   "nome":"João Silva",
   "cidade":"Campinas"
}

Conceitos Trabalhados

  • SQLite
  • Persistência Local
  • Consulta por Chave Primária

Parte 6 - API 4: Consulta Financeira

A API será responsável por consultar as informações financeiras armazenadas no Firebase.

Endpoint

GET /financeiro/1

Retorno

}

Conceitos Trabalhados

Parte 7 - API de Consolidação

A API central executará todas as consultas e consolidará os dados do cliente.

Fluxo de Execução

Recebe Cliente
      ↓
Consulta Compras
      ↓
Consulta Cadastro
      ↓
Consulta Financeiro
      ↓
Monta Documento JSON
      ↓
Envia ao MongoDB

Endpoint

POST /consolidar/1

Documento Gerado

{
  "cliente":{
      "codigo":1,
      "nome":"João Silva",
      "cidade":"Campinas"
  },

  "compras":[
      {
          "valor":1500
      },
      {
          "valor":2000
      }
  ],

  "financeiro":{
      "limite":50000,
      "saldo":12000
  }
}
