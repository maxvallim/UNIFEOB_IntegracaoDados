ETL com KNIME Analytics Platform

Objetivo da Aula:
Entender os conceitos de ETL (Extract, Transform and Load) utilizando o KNIME Analytics Platform e construir fluxos de integração de dados com diferentes fontes corporativas.

O que é o KNIME?

O KNIME Analytics Platform é uma plataforma visual de integração, preparação, transformação, análise e automação de dados.

Seu principal diferencial é permitir a criação de processos utilizando uma interface gráfica baseada em nós (nodes), eliminando grande parte da necessidade de programação.

Principais Possibilidades

  • Integração de dados corporativos
  • Processos ETL e ELT
  • Data Warehouse
  • Business Intelligence
  • Machine Learning
  • Automação de relatórios
  • Tratamento de planilhas Excel
  • Integração com bancos relacionais
  • Integração com bancos NoSQL
  • Extração de dados de APIs REST
  • Leitura e geração de documentos Word e PDF
  • Envio automatizado de e-mails
  • Processamento de grandes volumes de dados

O Conceito de ETL

Extract (Extração)

Leitura dos dados a partir de uma origem.

Transform (Transformação)

Limpeza, enriquecimento, validação e tratamento das informações.

Load (Carga)

Gravação dos dados processados em um destino.

Primeiro Workflow

Fluxo:

Excel Reader
      ↓
Row Filter
      ↓
Excel Writer

Excel Reader (Extract)

Objetivo: Ler dados de uma planilha Excel.

  1. Inserir o nó Excel Reader.
  2. Selecionar o arquivo Excel.
  3. Visualizar colunas e tipos de dados.
  4. Executar o nó.
  5. Abrir a tabela de saída.

Row Filter (Transform)

Objetivo: Filtrar registros.

Exemplos:

  • Clientes do estado SP
  • Vendas acima de R$ 1.000
  • Excluir registros nulos
  • Filtrar produtos ativos

Excel Writer (Load)

Objetivo: Gravar o resultado final em um novo arquivo Excel.

  1. Configurar o caminho do arquivo.
  2. Definir substituição ou criação.
  3. Executar o nó.

Exercício Básico

Considere a tabela:

Cliente Cidade Estado Valor
João Campinas SP 1500
Maria Belo Horizonte MG 800
Carlos Ribeirão Preto SP 2200
Ana Curitiba PR 500

Atividade

  • Ler a planilha
  • Filtrar apenas SP
  • Salvar como Clientes_SP.xlsx

Relação de Exercícios Práticos

Exercício 1 - MySQL

Conectar ao banco MySQL da empresa e extrair a tabela CLIENTES.

  • MySQL Connector
  • DB Table Selector
  • DB Reader
  • Excel Writer
Objetivo: Exportar os clientes ativos para Excel.

Exercício 2 - PostgreSQL

Ler a tabela PEDIDOS e calcular o total de vendas por estado.

  • PostgreSQL Connector
  • DB Reader
  • GroupBy
  • Excel Writer
Objetivo: Criar relatório consolidado.

Exercício 3 - MongoDB

Consumir uma coleção de pedidos armazenada em MongoDB.

  • MongoDB Connector
  • MongoDB Reader
  • Column Filter
  • JSON to Table
Objetivo: Transformar documentos JSON em tabela estruturada.

Exercício 4 - SQLite

Ler uma base local SQLite contendo informações de estoque.

  • SQLite Connector
  • DB Reader
  • Row Filter
  • Excel Writer
Objetivo: Exportar apenas produtos com estoque baixo.

Exercício 5 - Firebase

Consultar dados de uma coleção Firebase Firestore.

  • REST API Consumer
  • JSON Parser
  • Table Creator
  • Excel Writer
Objetivo: Gerar relatório dos usuários cadastrados.

Exercício 6 - DuckDB

Realizar análise analítica local utilizando DuckDB.

  • DuckDB Connector
  • DB Query Reader
  • Sorter
  • GroupBy
Objetivo: Calcular ranking de vendas.

Exercício 7 - Geração de Documento Word

Após consolidar os dados das vendas:

  • Ler dados de Excel
  • Criar resumo executivo
  • Gerar arquivo Word automatizado
Objetivo: Produzir relatório gerencial automaticamente.

Exercício 8 - Envio Automático de E-mail

Após gerar um relatório:

  • Ler resultado final
  • Anexar relatório
  • Enviar e-mail automaticamente
Objetivo: Automatizar distribuição de indicadores.
